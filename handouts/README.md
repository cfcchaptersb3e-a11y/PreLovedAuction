# Handouts

One-page sheets for the chapter, in the auction's own colours and using real
screenshots of the app rather than drawings of it. A4, 300dpi — the same file
works pasted into a group chat and pinned to a noticeboard.

| Sheet | For |
| --- | --- |
| `create-an-account` | Anyone joining the auction |
| `how-to-place-a-bid` | Bidders |
| `the-live-auction-night` | Everyone, before the finale |
| `role-cataloger` | The helper listing items |
| `role-treasurer` | The helper collecting payments and running the console |
| `role-organizer` | Whoever is running the drive |

## Regenerating them

The screenshots come from the app actually running, so a sheet is only as
current as the last time this was run. Re-run it after anything that changes a
label, a button or a page people are told to look for.

```bash
npm run handouts:seed        # sample auction: items, bids, a live lot, helpers
npm run build && npm start   # the app the pictures come from
node handouts/shoot.mjs      # photograph it   (needs: npm i -D playwright)
npm run handouts             # render every sheet  (needs: npm i -D qrcode)
```

Output lands in `handouts/out/`. The PDFs are committed because they are what
gets printed and passed around; the PNGs and the intermediate screenshots are
not, because they are regenerated by the command above and a stale screenshot
showing an old version of a page is worse than no screenshot at all.

`npm run handouts` prints a line per sheet and fails if any content overflows
its page — the footer silently falling off the bottom is exactly the sort of
thing nobody notices until it is printed.

Playwright and qrcode are not project dependencies. They are needed only to
build handouts, so install them when you do and remove them afterwards.

## Changing what a sheet says

Everything is in `sheets.mjs` — the headings, the steps, the two-column panel
and the three notes at the foot. `template.mjs` holds the shared design; a new
sheet should not need to touch it.

Say what is true of the app as it stands. These are read by people who are
about to tap the thing being described, and a sheet that is subtly wrong is
worse than none: it teaches somebody to distrust the whole set.

## The auction's address

The header, the QR code and the closing panel all use `HANDOUT_URL`, which
defaults to the chapter's current address:

```bash
HANDOUT_URL=our-new-address.example npm run handouts
```
